// PHILOSOPHY

本站是一个 零 npm 依赖 的静态站点。Markdown 文件夹结构 + JSON manifest + Node 脚本 把数据渲染成 HTML。没有任何前端框架 —— 只有 ~150 行 vanilla JS 用于轮播/灯箱/搜索。Terminal brutalist 美学：等宽字体、硬边框、零圆角、CRT 扫描线、闪烁光标。

为什么？

  • 少依赖 = 易维护 —— npm install 不会失败，Node stdlib 已足够
  • Markdown = 写作友好 —— 想法文可以直接用任意编辑器写
  • 静态站点 = 永久 —— 没有数据库、没有服务端、没有跟踪
// STRUCTURE

7 个内容路由 + 4 个基础设施文件：/、/about/、/thoughts/、/collections/、/now/、/uses/、/search/、/feed.xml、/sitemap.xml、/robots.txt、/404.html。

源文件结构：

  • apps.json — 应用清单
  • site.json — 全站元数据 + thoughts 树
  • content/thoughts/**/*.md — 想法文正文
  • templates/*.html — 11 个 HTML 模板
  • assets/styles.css — 一份 CSS，所有页面
  • assets/app.js — vanilla JS
  • build.mjs — 单一构建脚本，无 npm 依赖
// CONTRIBUTE
